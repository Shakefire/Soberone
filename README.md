# Soberone — Mofada Protocol

> **Sleek, Minimalist, Clinically Grounded Sobriety Infrastructure.**

Mofada is a precision behavioral health system engineered for permanent addiction recovery and habit transformation. This repository contains the official high-performance Next.js landing page for the SoberOne / Mofada ecosystem.

---

## Architectural Principles

- **No AI Slop:** Built without floating card clutter or multi-color gradients. Pure solid color discipline, hairline typographic grids, and high-density information architecture.
- **Brand Palette:** Deep authoritative navy (`#0C3C60`), clinical cyan (`#31C1D7`), recovery emerald (`#00B894`), high-contrast slate typography (`#0F172A`), and clean border rules (`#E2E8F0`).
- **Real-Time Crave Interception:** Interactive 4-4-4-4 Box Breathing visualizer and 5-4-3-2-1 Somatic Grounding tool engineered for the acute 300-second craving window.
- **Day 90 Biometric Certification:** 3-phase milestone verification funnel (Day 0 biometric photo pledge $\rightarrow$ Day 90 split-view transformation & mastery quiz $\rightarrow$ Telehealth specialist evaluation).
- **Reformed Rewards Hub:** Philanthropic capital grants ($5,000 venture seed funds, tech workstations, tuition sponsorships, trade toolkits).
- **Crisis Safety Standard:** Emergency helplines (SAMHSA 988) strictly centralized in Support Hub without panic clutter.

---

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Solid Brand Palette)
- **Icons:** Lucide React
- **Deployment Target:** Vercel

---

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
# Open http://localhost:3000

# Build production bundle
npm run build

# Start production server
npm start
```

---

## Deploy to Vercel

```bash
# Using Vercel CLI
npx vercel
# Or connect this repository directly in the Vercel Dashboard (https://vercel.com)
```
